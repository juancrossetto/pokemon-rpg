# Retratos de entrenadores

Retratos maestros transparentes de 400×240 usados dentro de las cards y en
la introducción de batalla. `thumbs/` contiene recortes derivados de 80×80
para nodos y listados.

- 25 retratos son sprites VS oficiales de sexta generación obtenidos de
  [WikiDex](https://www.wikidex.net/wiki/Categor%C3%ADa:Sprites_de_otros_entrenadores_Pok%C3%A9mon_de_la_sexta_generaci%C3%B3n).
- Los ocho restantes usan recursos oficiales de otros videojuegos: Let’s Go
  (`biker`, `gambler`, `supernerd`), Diamante Brillante/Perla Reluciente
  (`birdkeeperf`, `psychic`, `skier`, `skierf`) y el modelo oficial local de
  Recluta Rocket (`rocketgrunt`). No se usa arte generado por IA.

Los nombres coinciden con los slugs internos resueltos en `src/lib/avatars.ts`.
